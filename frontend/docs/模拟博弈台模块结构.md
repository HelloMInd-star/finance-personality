## 四、日志事件流

```mermaid
sequenceDiagram
    participant User as 用户
    participant UI as 界面组件
    participant Logger as logger.session
    participant Engine as gameTableEngine
    participant Storage as localStorage

    User->>UI: 调整参与人数滑块
    UI->>Logger: 博弈台-切换人数 {人数: v}
    
    User->>UI: 点击开始博弈
    UI->>Engine: createGame() + startNewRound()
    UI->>Logger: 博弈台-开始博弈 {参与人数}
    
    loop 每轮决策
        User->>UI: 弃牌/跟注/加注/All-in
        UI->>Engine: executeAction() + advanceToNextPlayer()
        UI->>Logger: 博弈台-决策 {动作, 金额, 阶段}
        Engine-->>UI: 返回更新后的 game state
    end
    
    User->>UI: 点击再来一局
    UI->>Engine: startNewRound()
    UI->>Logger: 博弈台-新一局 {局数}
    
    User->>UI: 点击结束对局
    UI->>Engine: saveGameRecord()
    UI->>Storage: 写入 gameTableSessions
    UI->>Logger: 博弈台-结束对局 {结果, 对局数, 时长}
```

## 五、4-Tab 代码结构速览

### 5.1 主组件骨架
```javascript
const GameTablePage = () => {
  const [activeTab, setActiveTab] = useState('lobby');

  return (
    <div className="gametable-page">
      {/* 页面标题栏 */}
      <div className="gametable-page-header">...</div>

      {/* Tab 导航 */}
      <Tabs activeKey={activeTab} onChange={setActiveTab} items={[
        { key: 'lobby',    label: '🎮 入口大厅' },
        { key: 'trainer',  label: '⚡ 博弈对战' },
        { key: 'stats',    label: '📊 数据统计' },
        { key: 'behavior', label: '🗄️ 行为采集' },
      ]} />

      {/* Tab 内容 */}
      {activeTab === 'lobby'    && renderLobby()}
      {activeTab === 'trainer'  && <GameTableTrainer />}
      {activeTab === 'stats'    && renderStats()}
      {activeTab === 'behavior' && renderBehavior()}
    </div>
  );
};
```

### 5.2 Tab 内容对照表

| Tab Key | 渲染方式 | 核心数据来源 | 主要组件 |
|---------|---------|-------------|---------|
| `lobby` | 纯函数 `renderLobby()` | `gameTableEngine.analyzeGameBehavior()` | 英雄卡 + 统计卡 + 数据类型卡 |
| `trainer` | 组件 `GameTableTrainer` | `gameTableEngine` 全部 API | PlayerCard / CommunityCards / OppAnalysisPanel / ActionLog |
| `stats` | 纯函数 `renderStats()` | Engine + `storage.get('gameTableSessions')` | 总览卡 + 核心指标 + 行为标签 + 历史记录 |
| `behavior` | 纯函数 `renderBehavior()` | `COLLECTED_DATA_TYPES` 常量 | 样本统计 + 数据详解 + 使用流程 + 隐私说明 |
